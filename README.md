# Calibration Engineering Project

A comprehensive project demonstrating calibration principles, procedures, and best practices in chemical engineering.

## Overview

This project showcases practical knowledge of calibration engineering including:
- Instrument calibration procedures
- Calibration standards and traceability
- Uncertainty analysis
- Quality management systems
- Advanced data analysis and statistical methods

## Key Features

1. **Calibration Procedures** - Step-by-step guides for common instruments
2. **Uncertainty Analysis** - Statistical methods for measurement uncertainty
3. **Quality Management** - ISO 9001/ISO 17025 compliance and calibration records
4. **Data Analysis** - Advanced statistical methods and control charts
5. **Traceability** - Documentation of calibration standards

## Technical Skills Demonstrated

- Python programming for data analysis
- Statistical analysis and uncertainty calculations
- Calibration curve generation
- Quality management system implementation
- Measurement system analysis (MSA)
- Control chart analysis
- Documentation and technical writing

## Calibration Standards

This project follows:
- ISO 9001:2015 Quality Management Systems
- ISO/IEC 17025 General requirements for calibration laboratories
- NIST guidelines for measurement uncertainty
- GUM (Guide to the Expression of Uncertainty in Measurement)
